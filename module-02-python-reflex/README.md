# Module 02: Python and Reflex

## Learning Objectives

- Master Python programming for data analysis
- Work with sports data using pandas and numpy
- Build interactive dashboards with Reflex
- Create advanced visualizations with matplotlib and seaborn

## Prerequisites

- Basic Python knowledge
- Understanding of data structures and algorithms
- Completion of Module 01 (recommended but not required)

## Getting Started

This module uses a dev container with Python and Reflex pre-installed. To get started:

1. Make sure you have Docker and VS Code with the Dev Containers extension installed
2. Open this folder in VS Code
3. When prompted, click "Reopen in Container"
4. Wait for the container to build and install dependencies

## Contents

- `app.py`: Starter Reflex application template
- `rxconfig.py`: Reflex configuration file
- `data/`: Sample sports data files
- `exercises/`: Practice exercises
- `assignments/`: Module assignments

## Running Your Reflex App

Once in the dev container, you can run your Reflex app with:

```bash
reflex run
```

The app will be accessible at:
- Frontend: http://localhost:3000
- Backend: http://localhost:8000

## Development

Initialize your Reflex app:

```bash
reflex init
```
