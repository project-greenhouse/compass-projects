# Compass Projects - Sports Data Science Course

This repository contains various learning modules and assignments for an online sports data science course. Each subdirectory represents a separate module with its own development environment, allowing students to work across different languages and frameworks throughout the course.

## Repository Structure

Each module is self-contained with its own dev container configuration, enabling seamless switching between different technology stacks:

- **module-01-r-shiny**: Introduction to sports data visualization with R and Shiny
- **module-02-python-reflex**: Building interactive dashboards with Python and Reflex

## Getting Started

Each module directory contains:
- A `.devcontainer` folder with the development environment configuration
- Module-specific README with learning objectives and instructions
- Starter code and data files
- Assignment templates

## Prerequisites

- [Docker](https://www.docker.com/products/docker-desktop) installed on your machine
- [Visual Studio Code](https://code.visualstudio.com/) with the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

## How to Use

1. Clone this repository
2. Open the repository in Visual Studio Code
3. Navigate to the module you want to work on
4. Click "Reopen in Container" when prompted, or use the Command Palette (F1) and select "Dev Containers: Reopen in Container"
5. Select the specific module's dev container
6. Start coding!
